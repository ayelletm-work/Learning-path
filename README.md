# גאיה לומדת

## קישור לאפליקציה (GitHub Pages)

[פתיחת גאיה לומדת](https://ayelletm-work.github.io/Learning-path/)

> הקישור הוא כתובת הפריסה שהוגדרה לפרויקט. זמינות האתר תלויה בהפעלת GitHub Pages ובהצלחת תהליך הפריסה.

אבטיפוס React + TypeScript + Vite בעברית RTL. כולל 13 מקצועות, מסלול חשבון, נגן הדרכה מונפש ב-SVG, קריינות עברית דרך Web Speech API (אם זמינה במכשיר), התנסות בשברים ו-3 שאלות עם משוב.

## הרצה

```bash
npm install
npm run dev
```

## בדיקה

```bash
npm run build
```

## מגבלות

זהו אבטיפוס ללא התחברות, שמירת התקדמות בענן או קובצי וידאו מוקלטים. יתר המקצועות אינם כוללים שיעורים פעילים. אין לפרסם כיישום לילדים ללא בדיקות פרטיות, נגישות ותוכן.
